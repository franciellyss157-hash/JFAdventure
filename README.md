# Dragão Ascendente
 
Protótipo jogável em HTML/CSS/JS para o jogo mobile descrito.
 
## O que já tem
 
- Tela inicial com dragão e botão Jogar
- Bloqueio de orientação em paisagem
- Cadastro de nome e usuário
- Batalha teste com ataque, defesa e agilidade
- Tela de concluído
- Hub principal com coleção, caixas, batalha, campanha e história
- 10 personagens com habilidades diferentes
- Moedas para comprar caixas
- Diamantes para upar personagens
 
## Como rodar
 
Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático.
